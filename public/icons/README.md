# PWA Icons

## Iconos Placeholder

Estos son iconos placeholder temporales para la PWA. Para crear iconos profesionales:

### Opción 1: Usar herramientas online
1. Ir a https://realfavicongenerator.net/
2. Subir un logo de 512x512px
3. Descargar el paquete de iconos
4. Reemplazar estos archivos

### Opción 2: Usar Figma/Photoshop
1. Crear un canvas de 512x512px
2. Diseñar el logo
3. Exportar en los tamaños necesarios (192x192 y 512x512)

### Opción 3: Generar desde SVG
```bash
# Si tienes ImageMagick instalado
convert -background none -resize 192x192 icon.svg icon-192.png
convert -background none -resize 512x512 icon.svg icon-512.png
```
